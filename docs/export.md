# ZIP 匯出（標準層）

右上角選單裡的「匯出 ZIP」會把所有資料夾、筆記與圖片打包成 `MDrawer-年-月-日.zip` 下載。程式在 `src/lib/export.ts`（讀資料、下載圖片）與 `src/lib/exportPlan.ts`（決定路徑）。

## ZIP 裡有什麼

```
MDrawer-2026-11-25.zip
├── 課程/
│   ├── 第一週/
│   │   ├── 課堂筆記.md            ![](架構圖.webp)、![](../../logo.webp)
│   │   ├── 架構圖.webp            圖片放在它在 App 裡的位置
│   │   └── 截圖-20261126-153012.jpg   Safari 貼的圖是 JPEG
│   └── 問題_答案_.md              原名「問題:答案?」
├── 空的資料夾/                    空資料夾也會保留
├── logo.webp
└── 首頁.md
```

- **資料夾結構**照 App 裡的樣子，筆記存成 `.md`；名稱已經是 `.md` 結尾的不會變成 `.md.md`。
- **圖片**放在它所在的資料夾，名稱照用；名稱沒有 `.webp`、`.jpg` 時依格式加上。筆記照原樣存檔：筆記用相對路徑引用圖片（`![](架構圖.webp)`、`![](../共用/logo.webp)`），ZIP 裡的位置跟 App 裡一樣，解壓後用其他 Markdown 編輯器也找得到。複製出來、共用同一個檔案的圖片各自放一份。
- **名稱被淨化時連結會斷**：資料夾或圖片的名稱有 `< > : " | ? *` 等字元時，ZIP 裡的名稱換成 `_`，筆記裡的相對路徑沒有跟著改。
- **檔名淨化**（spec 第 7 節）：Windows、macOS 不允許的字元 `< > : " | ? *` 換成 `_`，去掉結尾的點與空白，Windows 保留名稱（`CON`、`NUL`、`COM1`…）前面加 `_`。
- **撞名**：淨化後同名（不分大小寫）時加上「 (2)」，圖片的編號放在副檔名前面。
- **檔案時間**是筆記最後修改的時間。

## 匯入（加分層）

資料夾或空白處的右鍵選單有「匯入檔案」（`.md`、`.markdown`、圖片、`.zip`，可以多選）與「匯入資料夾」；大螢幕也可以從電腦直接拖到樹裡。程式在 `src/lib/importPlan.ts`（分類、名稱、圖片連結的改寫）與 `src/lib/import.ts`（讀檔案、展開 ZIP、建立項目），規則見 spec 第 3 節「匯入」。

- **匯出的 ZIP 可以匯入回來**：放進以 ZIP 檔名命名的資料夾（例如「MDrawer-2026-11-26」，撞名時加「 (2)」），結構、筆記內容與圖片都跟匯出前一樣；WebP、JPEG 照原樣上傳，不會再壓縮一次。
- **圖片的名稱變了，連結跟著改**：PNG 等格式壓縮後副檔名會變（`a.png` → `a.webp`），撞名時會加編號，筆記裡指到這些圖片的連結會改成新的名稱。
- **離線**時也能匯入（11/27 起包含圖片）：圖片先存在這台裝置，恢復連線同步時上傳，結果會說明「圖片將在恢復連線後上傳」。

| # | 操作 | 預期結果 |
| --- | --- | --- |
| 5 | 把驗證 1 下載的 ZIP 從 Finder／檔案總管拖到 MDrawer 的樹（或在空白處按右鍵「匯入檔案」選它） | 多一個「MDrawer-年-月-日」資料夾，裡面的結構、筆記與 App 裡原本的一樣，有圖片的筆記預覽正常 |
| 6 | 右鍵「匯入資料夾」，選一個用其他 Markdown 編輯器寫的資料夾（裡面有 PNG 圖片與其他檔案） | 筆記、圖片照原本的結構匯入，PNG 變成 `.webp`、筆記裡的連結跟著改；其他檔案略過，側欄上方說明略過幾個 |

## 已知限制

- **macOS 終端機的 `unzip` 指令**不認得 ZIP 的 UTF-8 檔名旗標，中文檔名會出錯。用 Finder 雙擊解壓、或在終端機用 `ditto -x -k 檔名.zip 目的資料夾` 就正常。Windows 10 以後的檔案總管、7-Zip 也都正常。
- **找不到的圖片**（例如 Storage 裡已被刪除）不會放進 ZIP，對話框會顯示數量。筆記裡仍保留它的相對路徑。
- **匯入**只改寫圖片的連結，SVG 等不支援的檔案略過（連結照原樣留著），舊工具壓縮、檔名不是 UTF-8 的 ZIP 檔名會變成亂碼；其他限制見 spec 第 8 節。
- **匯出讀的是這台裝置的資料**（離線 L2 起）：包含還沒同步到雲端的修改。圖片仍要從雲端下載，所以離線時不能匯出（離線時插入、還沒上傳的圖片從這台裝置讀）。剛打的字若還沒存好（右上角不是「已儲存」），不會出現在 ZIP 裡。
