專題名稱：MDrawer

應用：許多筆記工具會自動分類或替使用者整理內容，資料存在自家格式裡不容易帶走，網路不穩時也常常打不開。本專題建立一個以資料夾為核心的個人 Markdown 筆記空間，目錄完全由使用者自己建立與整理，系統只負責存放、預覽、離線使用與匯出。使用者可以把它安裝到手機或電腦主畫面，沒有網路時仍能閱讀筆記，也能隨時把全部資料匯出成標準 Markdown 帶走。

核心功能：
- 自訂資料夾樹：使用者自行建立、改名、移動、刪除資料夾與筆記，支援多層目錄，系統不做任何自動分類。
- Markdown 編輯與即時預覽：支援標題、清單、表格、程式碼區塊、圖片，預覽內容經過 XSS 過濾。
- 貼圖自動壓縮上傳：在編輯器直接貼上截圖，前端壓縮成 WebP 後上傳並插入筆記，同時顯示壓縮前後大小。
- 離線使用：以 PWA 安裝到主畫面，斷線時仍可開啟並閱讀所有筆記，進一步支援離線編輯並在恢復連線後自動同步。
- 資料匯出：一鍵匯出 ZIP，保留資料夾結構與圖片，解壓後可用任何 Markdown 編輯器開啟。

技術：
- Frontend：Vite / React / TypeScript（RWD 響應式設計）
- PWA：vite-plugin-pwa（安裝到主畫面、離線外殼）
- Backend：Supabase（Auth 帳號登入、PostgreSQL 資料庫、Storage 圖片儲存）
- 資料安全：Row Level Security，限制每位使用者只能存取自己的資料
- 離線儲存：IndexedDB（本機資料鏡像與待同步佇列）
- Markdown：markdown-it 搭配 DOMPurify 防範 XSS
- 圖片與匯出：Canvas 轉 WebP 壓縮、JSZip 匯出
- 部署：Vercel（免費取得公開 URL）

AI 工具：
- Claude：規格討論與審查、資料表與同步流程設計、安全性檢查。
- Claude Code：依規格逐步實作功能、除錯與測試，每個功能完成後記錄提示與修改內容。
- Gemini：交叉檢查 Claude 產出的程式與設計，查證套件文件用法，輔助 UI 版面構想。
